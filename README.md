# testovoe_Media_108
Бинарная классификация с не сбалансированным классом и деплой на веб

# 1. EDA (Исследовательский анализ данных):

### Подсчёт пропусков (NaN):
- Код рассчитывает количество пропущенных значений в каждой колонке и выводит процент пропусков.
- Выводит колонки, где пропусков больше 30%.

### Преобразование строк с пустыми списками:
- Преобразует строки с пустыми списками ([]) в булевы значения True/False.
- Далее отбираются колонки, где более 95% строк содержат пустые списки и сортируются по убыванию.

### Удаление колонок с пропусками:
- Колонки с более чем 30% пропусков удаляются из DataFrame.
- Очищенный DataFrame сохраняется для дальнейшего анализа.

### Анализ нулевых значений:
- Рассчитывается процент нулевых значений в каждой колонке.
- Колонки с более чем 30% нулевых значений фильтруются и удаляются.
- Аналогичные действия выполняются для колонок с пустыми списками, если их процент в колонке превышает 98%.

# 2. Предобработка числовых данных:

### Выбор числовых столбцов:
- Из очищенных данных выбираются только числовые столбцы, что исключает текстовые и категориальные данные.

### Замена бесконечностей на NaN:
- Все значения Inf и -Inf заменяются на NaN, что предотвращает ошибку при вычислениях.

### Удаление строк с пропусками:
- Строки, содержащие NaN значения, удаляются из числового DataFrame.

### Добавление столбца с единицами для расчета VIF:
- Для вычисления мультиколлинеарности добавляется столбец с единицами.

# 3. Расчёт VIF (Variance Inflation Factor):

### Вычисление VIF:
- Для числовых признаков рассчитывается показатель инфляции дисперсии (VIF), который используется для определения мультиколлинеарности между признаками.
- Если VIF превышает 10 (или заданный порог), признак удаляется.

### Удаление признаков с высоким VIF:
- Признаки с высоким значением VIF удаляются для уменьшения мультиколлинеарности.


# 4. Анализ уникальных значений в колонке:

### Извлечение уникальных чисел:
- В колонке `ym:s:goalsID`, которая состоит из строк, представленных как списки, извлекаются уникальные числа.
- Используется метод `ast.literal_eval` для преобразования строки в список.

### Подсчёт частоты уникальных значений:
- Для каждого уникального числа в колонке подсчитывается, сколько раз оно встречается в каждой строке.
- Итоговый результат выводится в виде отсортированного словаря с количеством вхождений каждого уникального значения.

# 5. Выводы по EDA:
- Проблемы с данными, такими как пропуски, пустые списки и нулевые значения, были обработаны.
- Колонки с высоким процентом пропусков или пустых значений были удалены.
- Мультиколлинеарность была устранена путём удаления признаков с высоким VIF.
- Уникальные значения в колонке `ym:s:goalsID` были проанализированы и отсортированы по частоте.
- все методы помогли избавиться от малозначимых признаков и сильно кореллированных сроратив пространство с 400 до 100

### 6. Генерация признаков (Feature Engineering):

#### Преобразование временных признаков:
- Преобразована колонка с датами (`ym:s:dateTimeUTC`) в формат `datetime`, что позволяет извлекать компоненты времени.
- Извлечены час и минута из временной метки:
  - `hour`: час из временной метки.
  - `minute`: минута из временной метки.
- Введены синус и косинус для часа и минуты, чтобы учесть циклическую природу этих признаков:
  - `hour_sin` и `hour_cos`: синус и косинус для часа, нормализованный по 24 часам.
  - `minute_sin` и `minute_cos`: синус и косинус для минуты, нормализованный по 60 минутам.

#### Удаление временных колонок:
- Удалены исходные колонки с временными метками (`ym:s:date`, `ym:s:dateTimeUTC`, `ym:s:dateTime`), так как преобразованные признаки теперь могут быть использованы для дальнейшего анализа.

#### Обработка массивов в строках:
- Для колонок, содержащих строки, представляющие массивы (исключая колонку `ym:s:goalsID`), была добавлена новая колонка, которая хранит длину этих массивов:
  - Функция `get_array_length` преобразует строку в список и возвращает длину массива. Если элемент не является массивом, возвращается 0.

#### Результат:
- Колонки с синусом и косинусом для времени.
- Новые колонки с длиной массивов для строковых признаков.
# P.s:
- Вместо применения моделей которые будут описыват в признаках array было принято решение добавить признаков через саттистические методы а именно по длине массива информацию, в дальнейшем мы получим прирост описатеной способности модели

### 7. Генерация признаков для задачи классификации:

#### Преобразование целевого признака:
- Целевой столбец (`ym:s:goalsID`) был преобразован в бинарный формат:
  - Признак `target` принимает значение 1, если в колонке `ym:s:goalsID` присутствует строка `'333755569'`, и 0 — если нет.

#### Подготовка данных:
- Разделены данные на признаки (`X`) и целевой столбец (`y`).
- Для категориальных признаков:
  - Признаки типа `object` были обработаны с помощью `CatBoostEncoder`, который применяет метод кодирования для категориальных переменных.
  - Пропущенные значения в категориальных признаках были заполнены значением "missing".

#### Обработка пропусков:
- Для числовых данных пропущенные значения были заполнены медианой.
  
#### Разделение данных на тренировочную, валидационную и тестовую выборки:
- Данные были разделены на тренировочную, валидационную и тестовую выборки (80% для обучения, 20% для тестирования).
- Применен метод SMOTE для оверсемплинга, чтобы увеличить количество меньшинственного класса в тренировочной выборке.
- в колабе были реализована крос валидация со стратификацие для понимание качества модели 
#### Вывод по обучению:
