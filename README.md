# testovoe_Media_108
Бинарная классификация с не сбалансированным классом и деплой на веб

# 1. EDA (Исследовательский анализ данных):

### Подсчёт пропусков (NaN):
- Код рассчитывает количество пропущенных значений в каждой колонке и выводит процент пропусков.
- Выводит колонки, где пропусков больше 30%.

### Преобразование строк с пустыми списками:
- Преобразует строки с пустыми списками ([]) в булевы значения True/False.
- Далее отбираются колонки, где более 95% строк содержат пустые списки и сортируются по убыванию.

### Удаление колонок с пропусками:
- Колонки с более чем 30% пропусков удаляются из DataFrame.
- Очищенный DataFrame сохраняется для дальнейшего анализа.

### Анализ нулевых значений:
- Рассчитывается процент нулевых значений в каждой колонке.
- Колонки с более чем 30% нулевых значений фильтруются и удаляются.
- Аналогичные действия выполняются для колонок с пустыми списками, если их процент в колонке превышает 98%.

# 2. Предобработка числовых данных:

### Выбор числовых столбцов:
- Из очищенных данных выбираются только числовые столбцы, что исключает текстовые и категориальные данные.

### Замена бесконечностей на NaN:
- Все значения Inf и -Inf заменяются на NaN, что предотвращает ошибку при вычислениях.

### Удаление строк с пропусками:
- Строки, содержащие NaN значения, удаляются из числового DataFrame.

### Добавление столбца с единицами для расчета VIF:
- Для вычисления мультиколлинеарности добавляется столбец с единицами.

# 3. Расчёт VIF (Variance Inflation Factor):

### Вычисление VIF:
- Для числовых признаков рассчитывается показатель инфляции дисперсии (VIF), который используется для определения мультиколлинеарности между признаками.
- Если VIF превышает 10 (или заданный порог), признак удаляется.

### Удаление признаков с высоким VIF:
- Признаки с высоким значением VIF удаляются для уменьшения мультиколлинеарности.

# 4. Анализ уникальных значений в колонке:

### Извлечение уникальных чисел:
- В колонке `ym:s:goalsID`, которая состоит из строк, представленных как списки, извлекаются уникальные числа.
- Используется метод `ast.literal_eval` для преобразования строки в список.

### Подсчёт частоты уникальных значений:
- Для каждого уникального числа в колонке подсчитывается, сколько раз оно встречается в каждой строке.
- Итоговый результат выводится в виде отсортированного словаря с количеством вхождений каждого уникального значения.

# 5. Выводы по EDA:
- Проблемы с данными, такими как пропуски, пустые списки и нулевые значения, были обработаны.
- Колонки с высоким процентом пропусков или пустых значений были удалены.
- Мультиколлинеарность была устранена путём удаления признаков с высоким VIF.
- Уникальные значения в колонке `ym:s:goalsID` были проанализированы и отсортированы по частоте.
